# Changelog

## 1.0.0 — 2026-10-04

Release-ready cross-platform JazzClub package.

### Added
- Windows PowerShell installer
- Linux/macOS shell installer
- automatic backup of an existing JazzClub installation
- optional theme-only install mode
- Full App Display and Lyrics Plus integration styling
- unified back/forward navigation pill
- amber Encore hover/focus/press states
- amber current-track equalizer
- fixed walnut/amber sticky headers
- restored dark vinyl-style bottom Play/Pause knob with warm-white glyph

### Kept stable
- approved JazzClub dark walnut / amber / cream visual system
- mini-vinyl artwork and event-driven playback rotation
- Spotify-native track-row layout and visibility

### Removed
- obsolete large-vinyl experiment that was no longer bound by the stable runtime

### Not included
- Track Peek
